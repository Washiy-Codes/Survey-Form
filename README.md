# Community Development Survey Form

A simple and responsive survey form built with **HTML and CSS** to collect feedback for community development initiatives. It features a clean layout, easy-to-fill input fields, and an accessible design to encourage community participation.
## live project
[try here]( https://washiy-codes.github.io/Survey-Form/)

## Features
- Clean and minimal UI  
- Responsive design  
- Simple and user-friendly input fields  
- Built for community development feedback

## Technologies Used
- **HTML**
- **CSS**

## How to Use
Download or clone the project, then open the `index.html` file in your browser to view and interact with the form.
